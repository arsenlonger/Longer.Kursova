# ☣️ Гра "Бункер 2D: Судний День" (Longer.Kursova)

Повноцінна 2D соціально-стратегічна гра на виживання, розроблена на мові **Java** у середовищі **Eclipse IDE** із підключенням до **MySQL (MAMP)** для курсової роботи.

---

## 🎮 Основні можливості гри:

* **🤖 Одиночна гра з Ботами (ШІ):**
  * Алгоритм аналізу корисності персонажів ($U(p)$).
  * Динамічна генерація коментарів та звинувачень ботів українською мовою у чаті обговорення.

* **🌐 Мережева гра по локальній мережі (LAN Sockets):**
  * Підтримка створення кімнати (Host) на порту `9876` та підключення клієнтів по IP.

* **🌋 Система Катастроф та Генерації:**
  * 4 основні катастрофи (*Ядерна зима, Зомбі-апокаліпсис, Мутагенний Вірус, Сонячний Спалах*).
  * 20 професій, 15 хвороб, 20 предметів інвентарю та 8 унікальних спец-карт дій.

* **🏆 Розрахунок Виживання & Епілог:**
  * Оцінка підсумкового шансу виживання команди у відсотках (0-100%).
  * Генерація історії-епілогу про долю бункера через 5 років.

* **🗄️ Інтеграція з БД MySQL (MAMP `kursova_db`):**
  * Автоматичне створення таблиць `users`, `achievements`, `game_sessions`.
  * Збереження досвіду (XP), рівнів акаунту та історії ігор.

---

## 🛠️ Технологічний стек:

* **Мова розробки:** Java 17+ (Java 25)
* **Графічний інтерфейс:** Java Swing / Java2D
* **База даних:** MySQL 8.0 / MAMP Server
* **Драйвер БД:** MySQL Connector/J 8.3.0
* **Мережа:** Java Sockets (TCP/IP)
* **IDE:** Eclipse IDE

---

## 🚀 Як запустити проєкт:

1. Переконайтеся, що сервери **MAMP (Apache та MySQL)** запущені.
2. Відкрийте проєкт в **Eclipse IDE**.
3. Натисніть **`F5`** на папці проєкту `Longer.Kursova` для оновлення файлів.
4. Клацніть правою кнопкою на `src/main/Main.java` ➔ **Run As** ➔ **Java Application**.
